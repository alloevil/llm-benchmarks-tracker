# Changelog

All notable changes to the data model and tooling. Data additions are tracked in git history and the per-benchmark ledgers.

## 1.1.0 — 2026-09-04

### Added
- Simplified Chinese: `description_zh` (required) on every benchmark and evaluator, `README.zh-CN.md`, and a `/zh/` site page with `hreflang` alternates and a language switch. All generated by `scripts/build.py`; CI checks both READMEs for drift.

### Changed
- Benchmark tables (README and site) are sorted newest-first by `released` instead of by status.
- Site CSS moved to `static/style.css`, shared by both language pages.

## 1.0.0 — 2026-09-04

Rewrite.

### Changed
- Single source of truth: `data/benchmarks/`, `data/results/`, `data/evaluators/`, one file per entity, validated by JSON Schema 2020-12 (`schema/`).
- Results are an append-only ledger with `source.url`, `source.kind`, `accessed` and `conditions` per row; `current_sota` strings are gone.
- `status`, `contamination_risk`, `domains`, `source.kind` and `evaluator.kind` are closed vocabularies.
- `README.md` tables, `dist/index.html` and `dist/api/v1/*.json` are generated by `scripts/build.py`; CI fails on drift.
- Validator rewritten (`scripts/dataset.py`, `scripts/validate.py`): schema validation, filename/id agreement, dangling `supersedes`/`superseded_by`/`evaluators.benchmarks` references, percent range, future dates, ascending ledger order, duplicate rows, undeclared splits. Covered by `tests/`.
- English-first data and documentation.

### Removed
- `docs/*.md`, `research/*.json`, `data/timeline.json`, hand-written `index.html`: duplicated, mutually inconsistent copies of the data.

### Fixed
- Six benchmark entries pointed at unrelated arXiv papers (ARC-AGI-2, MMMU-Pro, RULER, BFCL, τ-bench, BrowseComp). All paper links are now verified against arXiv metadata.
- HLE task count (2,500, not 3,000), MMLU release year (2020), BrowseComp release (2025-04).
- Harness validation silently checked zero entries because of a key mismatch.
